# Honey Wagon Services: website concept

Static mockup for Honey Wagon Services Inc (330 Industrial Circle, Stoughton, WI), built by Madison Design Projects.

- `index.html`, `css/styles.css`, `js/main.js`: plain HTML/CSS/JS, no build step. Vercel serves it as-is.
- `BUILD-SCRIPT.md`: the site plan/spec (sources, copy, design system, breakpoints, SEO).
- Preview locally: `python3 -m http.server` and open http://localhost:8000.

Every fact on the page comes from public records or listings (FMCSA, AccessDane, BBB, Google listing data, Experience.com). Review quotes are verbatim. No prices, licenses, or service-area towns are claimed until the owner confirms them.

Hero photo: "Ashton Farm in Dane County, Wisconsin" by Corey Coyle, CC BY 3.0, via Wikimedia Commons (color adjusted).
